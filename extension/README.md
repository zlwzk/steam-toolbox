# Steam 工具助手 · 工坊批量订阅（浏览器插件）

这是 **Steam 工具助手** 的浏览器插件版本，只覆盖**创意工坊批量订阅 / 退订**；免费 DLC / 喜加一领取、库清理需要配合桌面版使用（见仓库根目录说明）。

## 兼容范围
- **浏览器**：Google Chrome、Microsoft Edge（均为 Chromium 内核，同一套扩展包通用）
- **系统**：Windows / macOS
- **类型**：Manifest V3，本地运行，不依赖后端服务

## 功能
- 一键订阅 / 退订当前页全部 Mod；可选「全部页（自动翻页）」
- 拟人节奏：随机间隔 + 批次冷却 + 429/5xx 指数退避
- 暂停 / 继续 / 取消，失败项精准重试，序号范围限定，日志可导出
- 设置与日志保存在浏览器本地存储，不上传

## 安装（开发者模式加载）

### Chrome
1. 地址栏打开 `chrome://extensions/`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择本 `extension` 目录（含 `manifest.json` 的目录）

### Edge
1. 地址栏打开 `edge://extensions/`
2. 左侧打开「开发人员模式」
3. 点「加载解压缩的扩展」，选择本 `extension` 目录

## 使用
1. 在浏览器中登录 Steam
2. 打开某游戏的创意工坊浏览页（URL 含 `?appid=`），页面右侧会出现工具面板
3. 选择「订阅本页全部 / 全部页（自动翻页）/ 退订本页全部」，可在 ⚙ 设置里调整节奏与翻页上限

## 隐私
- 扩展仅在 `steamcommunity.com` 页面内运行；通过 `chrome.cookies` 读取 `sessionid` 与登录态用于发起订阅请求，不读取、不上传账号密码
- 设置、任务状态与日志仅写入浏览器 `chrome.storage.local`，卸载扩展即清除

## 从 Release 安装
Release 附件中的 `steam-toolbox-workshop-extension.zip` 解压后，按上面「加载已解压/解压缩的扩展」选择解压出的目录即可。
