# 功能路线图与彩蛋清单

本文记录本工具已落地功能、建议后续加装的方向，以及轻量彩蛋。排序按「贴合现有架构、低风险、高实用性」优先；高风险或触碰平台规则的项明确列为不建议做。

## 一、已落地

### 1.3.0
- **库自动分类（完整版）**：只读本机 Steam 缓存，按标签加权 + 事实规则把库分进 30 个收藏夹，支持预览调整、备份写入与一键还原；写入前自动备份、Steam 运行中拒绝写盘、主文件原子替换。
- **完整版本机激活态**：未激活时完整版功能不进入导航，界面按其余功能自然排布；激活标记仅存本机数据库，不联网、不绑机器码、不跨用户或打包产物串通；后端受保护路由二次校验。
- **版本检测提示补强**：关于卡片明确并列当前版本与远程最新版本，网络不可达时给出明确说明而非误报「已是最新」。

### 1.2.0

- **启动即检测账号状态**：打开软件一次性读取 Key / SteamID / 本机 Profile 登录态痕迹，未就绪时总览顶部给出分步引导，导航「账号绑定」标红点；绑定完成后全局状态自动刷新，不重复弹窗、不重复索要信息。
- **账号页分步状态条**：SteamID → Web API Key → 浏览器登录态，三步各自显示就绪/待办状态。
- **自动更新检查**：只读查询 GitHub 最新 Release，与本机外部版号比对，有新版本时标题栏提示并跳转下载页；结果进程内缓存，网络失败静默按无更新处理，不上传任何本机信息。
- **外部版号 + 内部构建号**：`APP_VERSION` 为对外版本号，`BUILD_NUMBER` 为内部构建号，版本接口与标题栏同时可见，便于排查「同版号不同构建」。
- **隐私与本地存储**：Key / SteamID / 登录态 / 截图 / 日志全部落在本机 `data/`，不同机器实例彼此独立；登录态复用持久化浏览器 Profile，重启不丢失。

## 二、建议加装（按优先级）

### P0 · 低成本、贴合现有底座

- **本地数据备份 / 还原**：把 `data/` 内设置与数据库导出为一个加密/压缩备份包，换机或重装后一键还原；不经过云端。
- **关于页**：集中展示外部版号、内部构建号、开源仓库、更新检查入口、隐私说明与免责声明；版本角标点击即可打开。
- **空状态 / 里程碑文案**：清单为空或批量任务跑过一定数量时，轮换简短提示语，降低枯燥感（纯前端文案，无副作用）。
- **深色模式**：跟随系统或手动切换，复用现有 CSS 变量。

### P1 · 实用增强，需评估链路

- **多账号切换**：按账号隔离数据库与浏览器 Profile，下拉切换；当前为单账号模型，需在存储层加账号维度。
- **愿望单 / 降价提醒**：接入商店价格接口，定时巡检愿望单与关注游戏折扣，走现有定时调度器与 Webhook 通知。
- **工坊 Mod 统计与整理**：已订阅数量、收藏 / 忽略持久化、退订前的订阅清单留档导出。
- **清理模块回溯**：移除授权前自动导出一份「待移除清单」CSV，保留操作历史，便于反悔核对。
- **桌面系统通知**：批量任务完成时触发本地通知（Windows 通知中心 / macOS 通知中心），作为 Webhook 之外的备选。

### P2 · 远期 / 需较多投入

- **增量自动更新**：当前仅检查版本并跳转下载页；自动下载并替换 exe 需要安装包校验、签名与回滚机制，风险较高，待具备签名条件后再做。
- **成就 / 卡牌掉落提醒**：监控挂机掉卡、成就解锁等，需长期轮询与状态去重。
- **插件与桌面端数据互通**：浏览器插件工坊操作结果回写桌面端本地库，需约定本地接口契约。

## 三、轻量彩蛋

- **版本角标关于卡片**：点击标题栏版本号弹出关于信息（版本 / 构建号 / 仓库链接 / 更新状态）。
- **空状态文案轮换**：清单无数据时随机展示一句轻松提示，例如「仓库空空如也，先去扫一波免费 DLC」。
- **里程碑祝贺**：批量领取 / 订阅累计成功达到整数关口时，在进度区给出一句简短祝贺。
- **构建号彩蛋**：内部构建号在关于卡片中可见，方便对照反馈问题。

> 彩蛋均为纯前端表现，不触碰账号、不发起额外网络请求、不影响主流程。

## 四、明确不做（红线）

- 不绕过 Steam 登录、验证码、人机校验或风控机制；不自动处理付费下单。
- 不读取、不导出、不上传账号密码、Cookie、交易凭证等敏感材料。
- 不内置代理 / 翻墙通道，不伪造设备指纹规避封禁。
- 不做批量刷好评、刷库存、薅重复领取等违反 Steam 服务条款的操作。
- 默认保持保守限速；任何提速都以「遇阻即停、可退避」为前提。
